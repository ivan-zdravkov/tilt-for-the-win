# Tilt for the Win

The classic wooden ball-in-a-maze toy, on your phone. Tilt to roll the ball from the centre of the board to the
single hole. Wood, grass, stone and ice each change how the ball moves. A new maze every day, the same for everyone,
with a global daily leaderboard.

**iOS & Android — coming soon.** · Website: https://tilt-for-the-win.zdravkov.dev
